# BIDAR AWS Banner Editor

A static GitHub Pages banner editor.

## Files
- `index.html` — editor and PNG export
- `banner-source.png` — original BIDAR banner

## GitHub Pages
1. Create a repository.
2. Upload `index.html` and `banner-source.png`.
3. Enable GitHub Pages from the repository settings.
4. Open the generated Pages URL.

No server or database is required.
